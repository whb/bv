  - 源 URL 写死 `https://raw.githubusercontent.com/google/material-design-icons/master/symbols/android/`，**无自定义源地址选项**；缓存是 OkHttp HTTP Cache。

- 沙箱网络限制：本环境代理 127.0.0.1:3935 仅放行 github.com，**策略性拦截 raw.githubusercontent.com 及各类镜像**（curl/.NET/OkHttp 三种栈均失败：SSL handshake / Remote host terminated）。因此本沙箱内 `:symbols:kspKotlin` 无法联网拉取，不能在此重跑验证；但 build 脚本 dry-run 已 BUILD SUCCESSFUL 验证语法正确。
- 先前后台完整双架构构建 E6Pv93（`:app:assembleDefaultRelease -PdualAbi=true`）已 BUILD SUCCESSFUL，产出双架构 APK：`app/build/outputs/apk/default/release/BV_902_0.3.0.r902.ed2591f0.release_default_arm64_v7a.apk`（14MB，含 arm64-v8a+armeabi-v7a 各 4 个 .so）。
- 注意：改动 symbols/build.gradle.kts 的 ksp arg 会使 KSP 任务下次重跑一次（新输入），用户机器上首次会联网拉取并落地缓存目录，之后复用。若其网络同样需代理才能达 GitHub，可启用 proxy 选项（填其自身代理）。
