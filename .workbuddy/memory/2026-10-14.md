## 构建失败排查：libs 子模块未初始化
- 现象：`:player:core:compileDebugJavaWithJavac` 失败，报 "No matching variant of project :libs:ffmpegDecoder ... No variants exist"。
- 根因：`libs` 是 git submodule（.gitmodules 指向 https://github.com/aaa1115910/bv-libs.git），`git submodule status` 前缀为 `-`（未检出），磁盘上 libs/ 为空。settings.gradle.kts:31-33 include 了 :libs:av1Decoder / :libs:ffmpegDecoder / :libs:libVLC，但模块不存在 → Gradle 解析不到变体。
- 修复：`git submodule update --init --recursive`，checkout 5e300a5，libs/ 下 av1Decoder/ffmpegDecoder/libVLC/media3Container 均已就位。
- 教训：clone 仓库后必须先初始化子模块，否则 player 模块无法编译。
