## libs 子模块（whb/bv-libs）结构与接线状态
- `libs/` 是 git 子模块，存"为 bv 重编译/打补丁的 AAR"，各目录用 `artifacts.add("default", file("x.aar"))` 暴露为子项目。
- 实际接线情况：
  - `:libs:ffmpegDecoder`（Media3 FFmpeg 音频解码）✅ `player/core` implementation，经 `ExoMediaPlayer` 的 `DefaultRenderersFactory.setExtensionRendererMode` 按 `Prefs.enableFfmpegAudioRenderer`（TV 其他设置里的开关）启用，Media3 service 机制自动发现，无显式调用。
  - `:libs:av1Decoder`（Media3 AV1 软解，2.4MB）⚠️ settings 已 include 但**无模块依赖**——AV1 软解"备而未用"；想让旧 TV（无系统 AV1 解码器）播 AV1 只需给 player/core 加依赖 + 放开视频轨扩展渲染。
  - `:libs:libVLC`（81MB 补丁版：去 UserAgent 尾巴、改 native 加载路径）❌ 未 include 未使用；实际 VLC .so 来自 Maven `org.videolan.android:libvlc-all:3.7.6`（player/core:71）。
  - `:libs:media3Container` ❌ 未使用。
- 跨机器打包：需 `git submodule update --init --recursive`，否则 player:core 因缺 ffmpegDecoder AAR 编译失败。子模块工作区有用户自己的未提交改动（.gitignore/README.md），不要动。

## 扫码登录"成功但显示二维码已过期"修复
- 现象：TV/mobile 扫码登录，账号已登录成功，画面却显示"二维码已过期"。
- 根因：`AppQrLoginViewModel` 用 `timeTask(1000,1000,...)`（无条件周期 Timer）轮询，poll 网络耗时 >1s 时请求重叠；成功的 poll 会消费 auth_code，使在飞的旧 poll 返回 86038（过期），`state = qrLoginResult.state` 无条件写入 → 晚到的 Expired 覆盖 Success。
- 修复（`app/shared/.../viewmodel/login/AppQrLoginViewModel.kt`，TV/mobile 共用）：① 周期 Timer 换串行协程循环（`while(true){ delay(1000); checkLoginResult() }`，`checkJob: Job` 替代 `java.util.Timer`）；② `@Volatile terminalReached` 终态保护，Success/Expired 处理后丢弃后续结果，`requestQRCode()` 重置。
- 验证：shared/tv/mobile compileDebugKotlin BUILD SUCCESSFUL。
